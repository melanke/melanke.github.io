## Post

Every couple of years I throw out something I am good at and learn the replacement. That habit is most of my career.

In 2011 that meant Watch.js, a library that watched any plain JavaScript object for changes with ES5 getters and setters. It went past 2,000 stars, and Vue shipped reactivity on the same trick three years later.

2008 → jQuery inside a Java shop, because Ajax made everything else look slow
2010 → threw out server-side state, and JSF and JPA with it, too much magic
2011 → Backbone, state living in the browser
2011 → native Android, two years before Android Studio existed
2012 → Objective-C with manual memory management, which I do not miss
2014 → Node, because Java had no real answer for WebSockets yet
2024 → passkey login on a smart wallet, gasless
2025 → AI agents paying each other over x402

Being early is a side effect. Each one started with something breaking in front of me, never with a keynote.

What did you pick up early because production made you?
